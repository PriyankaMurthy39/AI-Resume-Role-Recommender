# 🚀 AI Resume Role Recommender

An AI-powered resume analysis platform that:

- Predicts career roles based on skills
- Calculates readiness percentage
- Detects skill gaps
- Suggests learning resources
- Provides motivational feedback

## 🛠 Tech Stack
- Python
- Flask
- NLP-based Skill Matching
- HTML, CSS (Modern UI)

## 📌 Features
- 10+ Tech Roles
- Industry-standard skill mapping
- Smart career suggestions
- Dashboard analytics UI

## 🚀 Future Improvements
- Weighted scoring
- NLP semantic matching
- PDF report generation
- Deployment to cloud
